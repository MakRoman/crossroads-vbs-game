# Crossroads — Путь Истины

Пиксельная мобильная игра для **International Bible Church VBS**.

Путешественник стоит на распутье: «ИСТИНА» или «ЛОЖЬ»? Веди героя по извилистой узкой тропе,
не сходи на обочину — а на каждом перепутье тебя ждёт каверзный моральный вопрос по Библии,
где самый «благочестивый» ответ часто оказывается ловушкой.

## Игровой процесс

- **3 уровня**: «Тропа мудрости» (день), «Дорога милосердия» (закат), «Узкие врата» (ночь)
- **9 каверзных вопросов** с объяснением и библейским стихом после каждого ответа
- **Механика «Милость»**: ошибся — получаешь второй шанс с подсказкой
- **Метр света**: верные ответы разгоняют тьму на экране
- **Звёзды** за уровень (до 9 за игру) и финальный экран с Матфея 7:13–14

## Управление

- 📱 Наклон телефона (гироскоп, DeviceOrientation) — кнопка включения на экране уровня
- 👆 Перетаскивание пальцем по экрану
- ⌨️ Стрелки ← → / A D на клавиатуре

Адаптировано под портретную и горизонтальную ориентацию, мобильные (375px+) и десктоп.

## Технологии

- React + TypeScript + Vite + Tailwind CSS
- Собственный пиксельный движок на Canvas (низкоразрешённый буфер + `image-rendering: pixelated`),
  мир генерируется процедурно: горы, ели, облака, развилки
- 8-битный звук синтезируется через WebAudio — без аудиофайлов
- Шрифты: Press Start 2P + VT323 (кириллица)

## Запуск

```bash
npm install
npm run dev    # разработка
npm run build  # сборка в dist/
```

## Структура

```
src/game/content.ts  — уровни, вопросы, стихи
src/game/engine.ts   — пиксельный движок (рендер, ввод, мир)
src/game/sound.ts    — 8-битный синтезатор
src/App.tsx          — экраны и игровая логика
public/logo.png      — логотип VBS (титульный экран)
```
